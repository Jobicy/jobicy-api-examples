# Security Policy

Do not disclose security vulnerabilities through public GitHub issues, discussion threads, or pull requests.

Report a suspected vulnerability privately through the official [Jobicy contact channels](https://jobicy.com/contact-us). Include the affected integration, impact, safe reproduction steps, and any relevant version information. Do not include real access tokens, webhook URLs, personal job-seeker data, or destructive exploit payloads.

If a credential was exposed, revoke or rotate it immediately. Keep `.env` files, locally persisted job state, platform credentials, and application-specific webhook URLs outside version control.
